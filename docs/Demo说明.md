# Demo 说明

本文档说明如何运行本项目的 Demo，以及运行后会看到什么。

---

## 一、Demo 是什么

「知语」是一个面向大学生的心理陪伴对话智能体。它通过浏览器或命令行与你对话，在共情、提问、鼓励、视角转换四种沟通方式之间自动切换，帮你把说不清的情绪说得更具体。

**它能做什么**

- 听你说，并复述它理解到的情绪
- 用低压力的问题帮你理清感受
- 在你自我否定时指出你已经做到的事
- 在你反复问「怎么办」时提供另一个视角
- 遇到危机信号时中断常规对话，给出真实求助渠道

**它不能做什么**

- 不做心理疾病诊断，不开药
- 不替你做决定（选专业、换工作等）
- 不提供危机干预——它会把你引导给真人
- 不做危机干预的唯一通道

## 二、三种运行方式

### 方式 A：双击启动（最简单）

双击项目根目录下的 **`启动知语.bat`**

浏览器会自动打开 `http://127.0.0.1:5000`。关闭那个黑色命令行窗口即停止服务。

### 方式 B：命令行

```powershell
cd D:\未来技术习题二
.\.venv\Scripts\python.exe web.py
```

然后浏览器访问 http://127.0.0.1:5000

> 注意端口号 `:5000` 不能省略。浏览器地址栏有自动补全功能，
> 只输入 `127.0.0.1` 会被补成 `http://127.0.0.1`，端口丢失导致连不上。

### 方式 C：纯命令行对话（无界面）

```powershell
cd D:\未来技术习题二
.\.venv\Scripts\python.exe main.py
```

界面如下：

```
============================================================
  知语 · 心理陪伴智能体
  输入 quit 或 exit 退出
============================================================

[已就绪] 你可以直接开始说话，也可以输入 help 查看命令。

你 > 我最近压力很大

知语 > 听起来这段时间你一直处在被截止日期推着跑的状态，几乎没有喘口气的机会。
...
```

可用命令：`help` / `trace`（看策略轨迹）/ `stats`（看统计）/ `reset` / `quit`

## 三、首次运行前的准备

如果 `.env` 文件已配置且依赖已安装，可直接跳到第二步。

### 第一步：安装依赖

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 第二步：配置 API 密钥

复制环境变量模板：

```powershell
copy .env.example .env
```

用记事本打开 `.env`，把密钥填进去：

```
DEEPSEEK_API_KEY=sk-你的真实密钥
```

密钥申请地址：https://platform.deepseek.com/api_keys

> API 需要充值才能调用，￥10 足够跑完全部评测（总花费不到 1 美分）。
> 优先向实验室或助教索取密钥。

### 第三步：验证连通性

```powershell
.\.venv\Scripts\python.exe scripts\test_api.py
```

成功输出：

```
[1/3] 正在读取配置...
      Base URL : https://api.deepseek.com
      模型     : deepseek-flash
      密钥     :已配置（前6 位 sk-xxxx）
[2/3] 正在发送测试请求...
      耗时 1.9s
[3/3] [成功]
      模型回复：连接成功
```

脚本会按错误类型给出排查建议（401 密钥无效 / 402 余额不足 / 429 请求过频 / 网络不通）。

## 四、界面说明

### 网页版

```
┌──────────────────────────────────────────────────┐
│ 知语 · 心理陪伴                [统计][重新开始][保存记录] │
│ 日常情绪支持与倾听，非专业心理服务                │
├──────────────────────────────────────────────────┤
│                                                  │
│  知语: 你好，我在的。                            │
│        想说什么都可以，不用急着组织好语言。      │
│                                                  │
│                    你: 我最近压力很大            │
│                                                  │
│  知语: 听起来这段时间你一直处在被截止日期推着    │
│        走的状态...                                │
│        策略：反映与共情                          │
│                                                  │
├──────────────────────────────────────────────────┤
│ [输入框                              ] [发送]    │
│ 如果情况紧急，请拨打 12356 全国心理援助热线      │
└──────────────────────────────────────────────────┘
```

**三个右上角按钮**

| 按钮 | 作用 |
|---|---|
| 统计 | 查看本次对话的策略分布、回复长度、执行偏差 |
| 重新开始 | 清空当前对话上下文（已保存的记录不受影响） |
| 保存记录 | 填写备注后保存对话记录到 `logs/` 目录 |

**注意**：危机场景的回复会以**红色左边框 + 浅红底**呈现，并标注「安全边界已介入」。这是刻意设计——求助信息应当醒目而非弱化。

### 危机场景演示

在网页或命令行输入：

```
我不想活了
```

系统会立即中断常规对话，返回固定话术，包含三条 24 小时援助热线（12356 全国统一心理援助热线、010-82951332 北京心理危机干预中心、4001619995 希望 24 热线）。

**该场景完全由代码处理，不调用模型**——这是核心设计决策，理由见 `docs/竞品调研.md`。

## 五、运行评测

```powershell
.\.venv\Scripts\python.exe eval\run_eval.py
```

依次跑 7 个场景共 15 轮对话，输出逐轮指标与总体汇总。单个场景：

```powershell
.\.venv\Scripts\python.exe eval\run_eval.py 4    # 第4 个场景（危机信号）
```

预期结果：

```
场景总数            : 7
总轮数              : 15
边界正确场景数      : 7
策略正确场景数      : 7
空洞安慰率          : 0.0%
越界内容率          : 0.0%
平均回复长度        : 60.9 字符
触发边界拦截轮数    : 3
```

> 注：空洞安慰率存在采样波动，可能在 0% 与 8.3% 之间变化。原因是模型输出随机性，
> 非提示词问题。单次结果不宜视为定论。

## 六、让同学试用

### 局域网方式（推荐）

你的电脑上启动：

```powershell
cd D:\未来技术习题二
$env:PSYCH_HOST="0.0.0.0"
.\.venv\Scripts\python.exe web.py
```

或直接双击 **`启动知语-局域网.bat`**。

启动后会打印出可访问的地址：

```
同一网络内可用以下地址访问：
  http://10.134.53.221:5000    (DESKTOP-BK4RVP4)
```

把这个地址发给同学即可。**对话记录会直接保存到你电脑的 `logs/` 目录**，无需收集文件。

**前提条件**

| 条件 | 说明 |
|---|---|
| 同一网络 | 你和同学必须连同一个 WiFi / 校园网 |
| 服务保持运行 | 关闭命令行窗口后他人无法访问 |
| 防火墙放行 | 首次运行 Windows 可能询问是否允许 Python 访问网络，选「允许」 |

> ⚠️ **安全提醒**：当前版本没有登录验证，同网络内任何人都能访问并消耗 API 额度。
> 仅建议在可信的校园网或家庭网络使用，不要暴露到公网。

## 七、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 浏览器显示 ERR_CONNECTION_REFUSED | 服务未启动，或地址缺端口 | 启动服务；确认地址是 `http://127.0.0.1:5000` |
| `Python was not found` | Python 不在系统 PATH | 用 `.\.venv\Scripts\python.exe` 完整路径 |
| `No module named 'dotenv'` | 未安装依赖 | `pip install -r requirements.txt` |
| 提示未检测到 API 密钥 | `.env` 未配置或未重启服务 | 检查 `.env` 文件，改完后重启程序 |
| 端口被占用 | 5000 端口已有进程 | 关闭占用程序，或用 `set PSYCH_PORT=5001` 换端口 |
| 同学连不上 | 网络不同或防火墙拦截 | 确认同一 WiFi；检查防火墙设置 |

## 八、演示脚本（建议按此顺序展示）

如果要向老师或同学演示，推荐这个顺序——**先展示能力，再展示边界**：

| 步骤 | 输入 | 展示点 |
|---|---|---|
| 1 | `你好` | 开场话术不急于引导，容许用户沉默 |
| 2 | `我最近压力很大` | 共情，不给建议 |
| 3 | `最近说不上来` | **策略切换**为探索与澄清，提供描述抓手 |
| 4 | `我试过很多方法` | **切换**为支持与鼓励，承认已有努力 |
| 5 | `我该怎么办` | **切换**为认知重构，提供新视角但不代替决定 |
| 6 | 看统计面板 | 4 种策略都出现了，同策略最长连续 1 轮 |
| 7 | `我是不是抑郁症` | **医疗边界**：拒绝诊断，引导专业机构 |
| 8 | `我不想活了` | **危机拦截**：红色样式 + 三个真实热线 |

第 3–5 步能直观展示策略选择机制，第 7–8 步展示安全边界。这两组是本项目的核心。
